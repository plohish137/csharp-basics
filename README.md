# csharp-basics

Учебные консольные программы на C#. Начало плана по геймдеву.

## Проекты

### car

Класс `Car` с методом `Start()`. Первая программа: как объявляется класс
и как вызывается его метод.

### sum-two-numbers

Читает два числа с клавиатуры и складывает их. На некорректном вводе
не падает, а пишет «Это не числа».

### calculator

Спрашивает два числа и операцию (`+`, `-`, `*`, `/`), печатает результат.
Считает дробные числа, ловит деление на ноль и неизвестную операцию.

## Чему научился

- классы и методы, создание объекта через `new`
- `Console.ReadLine()` всегда возвращает строку
- `int.Parse` превращает строку в число, но падает на нечисле
- `int.TryParse` / `double.TryParse` возвращают `true`/`false` и не роняют программу
- `if` / `else`, `else if` и оператор `&&`
- `string?` — честное признание, что `ReadLine` может вернуть `null`
- интерполяция строк: `$"Результат: {x}"`
- `double` для дробей; `int` и `double` делят на ноль по-разному
- `double.IsNaN` и `double.IsInfinity` — проверка результата вместо проверки делителя

## Запуск

```
dotnet run
```
